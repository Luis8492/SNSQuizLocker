# 公開前QAチェックリスト（v1.0.0）

方針: クイズの機能QAは `continue.html`（`chrome-extension://<id>/continue.html`）で
1プラグインずつ有効にして回す。サイトゲートQAは代表クイズ1つで6サイトを回す。
テーマはOS設定（またはDevTools → Rendering → Emulate prefers-color-scheme）で切替。

## 0. 準備

- [ ] `chrome://extensions` でデベロッパーモード → `extension/` フォルダを読み込み（最新の master）
- [ ] 拡張のエラー表示（「エラー」ボタン）が出ていない

## A. クイズ機能（continue.html、7種 × ライト/ダーク）

各クイズについて、オプションでそれだけを有効にし、1ラウンド完走 → 「続けて修行」で
もう1ラウンド。ライトで1周、ダークで1周。

共通確認項目:
- [ ] ヘッダーの判子バッジ・進捗スタンプ・「問 i / n」が正しく進む
- [ ] 正解 → 淡々と次へ／全問クリア → クリア後画面（続ける/解除の2択）
- [ ] 不正解時のフィードバックが読める（配色・コントラスト）
- [ ] コンソールにエラーが出ない
- [ ] コピー・貼り付け・右クリックが該当箇所でブロックされる

### A2. 今回追加: 漢字⇔かな許容（koten）

- [ ] ルビ箇所をかなで入力して正解になる（例: 硯→すずり）
- [ ] 一部だけかな書き（混在）でも正解になる
- [ ] よみを間違えると不正解のまま（例: ひぐらし→ひくらし）
- [ ] かなで書いて間違えた場合、diff がかな表記ベースで表示される
- [ ] 空欄で Submit → 原文（漢字）が「抜け」として表示される

## B. サイトゲート（6サイト、クイズは古典1つ有効で可）

各サイトで: オーバーレイが出る / クリア→解除で閲覧できる / 同タブ内は再ロックされない /
新しいタブで開き直すと再ロックされる。

| サイト | ゲート表示 | 解除 | 固有確認 |
|---|---|---|---|
| YouTube | [ ] | [ ] | 動画ごとにロック / ロック中は強制一時停止 / 広告中は止まらず消音で進み、広告明けの本編は停止＆解除後に音が戻る / 動画→動画のSPA遷移で再ロック / ショート(`/shorts/`)も対象 |
| X (x.com) | [ ] | [ ] | サイト単位ロック / twitter.com からのリダイレクトでも動く |
| Facebook | [ ] | [ ] | サイト単位ロック |
| Instagram | [ ] | [ ] | サイト単位ロック |
| TikTok | [ ] | [ ] | サイト単位ロック / 背後の動画音声が漏れない（強制停止が効く） |
| Reddit | [ ] | [ ] | サイト単位ロック |

- [ ] クリア後の「続けて修行」→ continue.html への遷移が全サイトで動く
  （web_accessible_resources の matches 漏れがあるとここで失敗する）
- [ ] 対象外サイト（例: google.com）では何も起きない

## C. オプションパネル

- [ ] ツールバーアイコンのクリックでポップアップが開く
- [ ] クイズ・サイトとも最後の1つはオフにできない
- [ ] 選択変更が保存され、開き直しても保持される（storage.sync）
- [ ] 変更が開いているタブの「次のゲート/次ラウンド」から反映される
- [ ] 新規プロファイルにインストール → オプションパネルが自動で一度開く（onboarding）
- [ ] 既定値: クイズ=全種 / サイト=YouTubeのみ

## D. 申請前パッケージ確認

- [ ] ZIP に含めるのは `extension/` 以下の全ファイル（ZIP のルート直下に
      manifest.json が来る形）。`android/`・`ios/`・`tmp/`・`scripts/`・`docs/`・
      `.git`・ルートの `README.md` は含めない
- [ ] ZIP 作成（リポジトリ直下で）:
      `git archive -o snsquizlocker-1.0.0.zip HEAD:extension`
- [ ] ZIP を展開して `chrome://extensions` に読み込み、エラーなく起動する
- [ ] `manifest.json` の version がストアに上げる版と一致
- [ ] プライバシーポリシーの公開URLが有効（リポジトリ公開後に確認）
